

## Vision & Purpose

Network automation is no longer optional — it is foundational for scalability, consistency, security, and operational efficiency.
The purpose of this repository is to:

- Centralize multiple automation tools and ideas in one place

- Provide production-grade scripts and methodologies used in real customer projects

- Share learnings from the field (Notes from the Field)

- Serve as a personal portfolio and framework for continued innovation

## Current Projects
✔ __APC NMC3 UI Scraper__ – UPS Security Automation

A headless/visible browser automation tool designed to audit, secure, and standardize the configuration of __APC UPS Network Management Card 3 (NMC3)__ devices.

Key features:

- Automated login using Playwright

- Password rotation and hardening

 - Creation of new admin accounts

- Full security remediation workflow

- CSV reporting for compliance

- Packaged as a standalone executable

Full documentation: [README](apc-nmc3-ui-scraper/README.md).
